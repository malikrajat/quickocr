How another extension calls it 
await chrome.runtime.sendMessage('<log-lens-extension-id>', {
  type: 'loglens.log',
  level: 'error',
  message: 'Checkout failed',
  details: error.stack,
  context: { route: '/checkout', status: 500 }
});
No page data. The API rejects unapproved senders, rate-limits to 60 entries per minute and applies the same redaction as automatic capture.
Privacy & data
No analytics. No telemetry. No remote code.

Log Lens redacts bearer headers, tokens, API keys, passwords, session ids, cookies and URL credentials before storage, export, email or sending. It never captures cookies, form data, request headers, request bodies or page content. Screenshots and exports are downloaded locally.
